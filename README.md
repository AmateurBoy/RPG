# TestedField (Unity)

Кооперативный изометрический прототип (до 4 игроков), перенесённый с Unreal Engine 5 (`../TestedField`, Blueprints) на Unity 6. Перенесены все готовые задачи UE-версии: P0-01…P0-12, P0-14, P0-17 — сеть, бой, мобы, смерть группы, карта из зон и её генерация, ворота, таймер забега, боссы, финальный босс, предметы, лут, HUD и активные навыки. Числа и данные те же, что в UE, только в метрах вместо сантиметров.

Подробности по системам — в [docs/](docs/) (те же 14 документов, что были в UE-проекте).

## Быстрый старт

Unity **6000.6.4f1**, пакеты ставятся сами из `Packages/manifest.json` (Netcode for GameObjects 2.13.3, URP, Input System, AI Navigation).

1. Открыть проект в Unity Hub.
2. Открыть сцену `Assets/TestedField/Scenes/TestField.unity` (тестовая площадка, бывшая `EmptyMap`) или `Run.unity` (карта забега) и нажать **Play**. Если сцена запущена напрямую, хост стартует сам, соло — как PIE в UE.
3. Полный поток с меню и лобби: сцена `MainMenu.unity` → «Создать игру» → «Начать игру».

Если ассетов нет или их нужно пересоздать: меню **TestedField → Setup Project (create missing)** создаёт недостающее, **Rebuild Generated Assets (overwrite)** пересоздаёт материалы, данные, префабы и сцены заново (ручные правки в них пропадут).

### Как пройти забег (сцена `Run`)

1. **Квест стартовой зоны** — найти голубой столб «Квест зоны (E)» (на карте зон справа вверху — «К») и нажать **E**. Это заглушка квеста зоны (P0-15, в UE не был сделан): квест засчитывается, списывается 1 день, открываются проходы на восток и север (зоны A и B).
2. **Боссы зон** — арены «Б» в стартовой зоне, A и B. Убитый босс открывает только свою арену; проход на запад, к финалу, открывается, когда побеждены **все три** босса зон.
3. **Финальный босс** — за западным проходом. Победа — «ПОБЕДА!».

Что нужно сейчас, показывает панель «Цели» под картой зон; у закрытых ворот внизу экрана написано, чем они открываются. В **точках интереса** (жёлтые столбы, на карте — жёлтые точки) стоит сундук с лутом. Лагеря НПС и входы в данж — пока только столбы с подписью «не сделано».

Если хочется, чтобы выходы из зоны открывал босс, а не квест, — в `Data/Zones/DA_RunMap_Default` поменять у связей `UnlockCondition` с `ZoneQuest` на `ZoneBoss`.

### Кооп

Хост — один из игроков (listen server), остальные подключаются по IP, порт **7777**, максимум 4 игрока. Для проверки в одиночку: собрать билд (File → Build Profiles, сцены уже в списке), в билде «Создать игру», в редакторе (сцена `MainMenu`) «Подключиться» на `127.0.0.1` — или наоборот. Через интернет — VPN вроде Hamachi/ZeroTier, как и в UE-версии.

Быстрый запуск нескольких окон из командной строки (каждая строка — отдельное окно):

```
TestedField.x86_64 -host -autostart 2 -name Хост -screen-fullscreen 0 -screen-width 960 -screen-height 540
TestedField.x86_64 -connect 127.0.0.1 -name Клиент -screen-fullscreen 0 -screen-width 960 -screen-height 540
```

`-host` — создать игру, `-autostart N` — хост сам начинает забег, когда в лобби N игроков, `-connect IP[:порт]` — подключиться, `-name` — имя игрока.

### Отладочная консоль (` или F1)

Замена `ke * Debug…` из UE; работает у хоста. Старые имена оставлены алиасами.

| Команда | Что делает |
|---|---|
| `regenerate 42` / `regenerate_random` | Пересобрать карту забега с seed 42 / случайным |
| `complete_quest Start` (`ZoneA`, `ZoneB`) | Засчитать квест зоны — открыть её ворота |
| `defeat_boss Start` (`ZoneA`, `ZoneB`) | Засчитать босса зоны без боя |
| `spawn_chest` | Сундук перед героем хоста |
| `spend_days PartyWipe` | Списать дни по причине из `RunTimer.DayCosts` |
| `give Sword` | Положить предмет в инвентарь героя хоста |
| `seed` | Seed текущей карты |

## Решения, принятые при переезде

- **Сеть — Netcode for GameObjects** (listen server, Unity Transport, подключение по IP) — прямой аналог встроенной репликации UE. Серверные RPC объявлены атрибутом `[Rpc(SendTo.Server)]`; ручной шаг «пометить Replicates в Details», который был нужен в UE, больше не нужен.
- **Движение героя — у владельца** (`NetworkTransform` в режиме Owner) — замена клиентского предсказания `CharacterMovement`. Урон, стамина, мана и состояния по-прежнему считает хост; телепорт и отбрасывание хост делает через RPC владельцу.
- **Карта забега собирается у каждого локально по seed.** Хост выбирает seed и номер удачной попытки, в сеть уходят только они и состояния (ворота, квесты, боссы, арены). Генератор детерминирован, поэтому карта у всех одинаковая — это и было TODO в UE-доке генерации. Сетевые объекты на карте — только боссы.
- **Заготовки зон — данные, а не префабы с геометрией**: прямоугольники клеток 4 × 4 м, пол и стены строятся по контуру автоматически (в UE заготовки тоже были сгенерированы из сетки клеток). Генератор дополнительно отклоняет попытку, если зоны пересекаются.
- **HUD — IMGUI** (аналог рисования на Canvas в `ReceiveDrawHUD`); меню и лобби — тоже IMGUI. Перевод на UI Toolkit — отдельная задача, если понадобится.
- **Ассеты генерируются кодом** (`TestedField → Setup Project`): материалы, данные с числами из UE-документации, префабы из примитивов, сцены. После генерации это обычные ассеты — их можно править в инспекторе.

### Значения, которых не было в UE-документации

В UE-доках не было чисел движения героя и камеры, а у боссов — радиусов и таймингов атак. Выбраны такие (всё правится в префабе `Hero` и в `DA_BossAttack_*`):

- Герой: шаг 4.5 м/с, спринт 7 м/с (тратит 10 SP/с; после истощения снова доступен с 20 SP), кувырок 4 м за 0.45 с, разворот 720°/с, во время удара скорость ×0.5. Статы: HP 100, MP 50 (+2/с), SP 100 (+25/с через 1 с после траты).
- Камера: поворот 45°, наклон 55°, дистанция 15 м (7–26 м колесом).
- Боссы: тайминги замаха 0.7–1.8 с, восстановления 0.6–1.2 с, радиусы кругов 1.5–4.8 м; скорость Громилы 3.3 м/с (×1.3 во 2-й фазе = 4.29, как в UE-проверке), финального — 3.2 м/с (×1.1 = 3.52).

## Тесты

Window → General → Test Runner → EditMode → Run All. Проверяется: один seed → одна карта, разные seed → разные карты, все 8 сочетаний заготовок не пересекаются, в каждой зоне есть арена, квест и POI, невыполнимое правило проваливает генерацию, слоты внутри зон, логика инвентаря (обмен, переполнение, перетаскивание), таблицы лута, формула модификаторов.

## Отличия от UE-версии и открытые вопросы

- В тестовой сцене стоит сундук `Chest_Test` для быстрой проверки лута (в `EmptyMap` его не было — только `DebugSpawnChest`).
- Подсказка предмета в инвентаре показывает название навыка, цену и перезарядку (в UE был только `SkillId` — это было в TODO).
- Квест зоны (P0-15) и точки интереса (P1-02) в UE не были сделаны, поэтому забег проходился только консолью. Здесь стоят заглушки: E у квестового столба засчитывает квест зоны, в точке интереса стоит сундук. Добавлено условие ворот `ZoneBoss`, а также панель целей и подсказки у ворот.
- Цвет акцента героя зависит от номера игрока (так проще различать союзников); в UE у всех был один материал.
- Открытые вопросы геймдизайна (баланс, дележ лута, квест зоны P0-15, экран итогов P0-13 и т.д.) перенесены как есть — см. разделы TODO в [docs/](docs/).
