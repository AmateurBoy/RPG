# Финальный босс (P0-10)

## Где финальный бой и как туда попасть

**Финальная локация — отдельная, четвёртая «зона» карты**, не одна из трёх зон забега: заготовка `Data/Zones/Layouts/Layout_Final_01` (комната 28 × 28 м с четырьмя колоннами, стены 3 м, коридор-вход с востока). Данные — `Data/Zones/DA_Zone_Final` (`ZoneId` `Final`, `IsFinalZone = true`).

Она пристыкована к карте обычной связью `RunMapData` (как зоны A и B, P0-05): `Start.Exit_West → Final.Entrance`. Для этого в обеих стартовых заготовках (`Layout_Start_01/02`) есть проход `Exit_West` на западной стене (x = −24 м и x = −20 м от `RunMap`). Где стоит финальная локация, меняется данными: другая связь (другая зона/проход) или другая заготовка в `DA_Zone_Final.Layouts`.

Navmesh строится по всем построенным зонам, расширять ничего не нужно (см. [zones.md](zones.md)).

## Условие доступа — данные

У каждой связи `RunMapData.Links` есть условие открытия ворот — `UnlockCondition` (`enum GateUnlockCondition`, по умолчанию `ZoneQuest`):

| Условие | Когда ворота открываются |
|---|---|
| `ZoneQuest` | выполнен квест зоны «откуда» (P0-07) |
| `AllZoneBosses` | побеждены боссы всех зон, кроме финальной (зоны с непустым `BossPrefabs` и `IsFinalZone = false`) |
| `Open` | сразу при сборке карты |
| `ZoneBoss` | побеждён босс зоны «откуда» (в UE не было; чтобы выходы из зоны открывал босс, а не квест, — поменять условие связи в `DA_RunMap_Default`) |

`DA_RunMap_Default`: `ZoneQuest`, `ZoneQuest`, **`AllZoneBosses`** (финальная локация).

Ворота хранят условие (`PassageGate.UnlockCondition`). `RunMap.UpdateGates` проверяет все закрытые ворота (`IsGateUnlocked`) и вызывается при выполнении квеста зоны и при победе над боссом зоны. Новое условие = новое значение `GateUnlockCondition` + ветка в `IsGateUnlocked`.

## Финальный босс

- `Prefabs/Network/Boss_Final` — префаб с `BossBase` (P0-09), данные `Data/Bosses/DA_Boss_Final`.
- Арена `Prefabs/Zones/BossArena_Final` — `BossArena` с `ArenaRadius = 10.5` м (у зон 7.5). Ставится в слот `BossArena` финальной локации (радиус слота 11 м) правилом `DA_Fill_FinalBossArena`; какой босс — `DA_Zone_Final.BossPrefabs`.
- Бой, телеграфы, закрытие арены, сброс при смерти группы — общие из P0-09 ([bosses.md](bosses.md)); смерть всей группы — P0-04 (списание дня + возрождение на старте, [party-death.md](party-death.md)).

|---|---|---|

| Фазы | 2–3 | 4 (75%, 50%, 25%) |

## Победа в забеге

Финальный босс умер → арена `Defeated` → `RunMap.NotifyZoneBossDefeated(Final)` → у зоны `IsFinalZone` → `RunGameState.DeclareVictory("FinalBoss")` (только хост):

- `RunWon = true` (`NetworkVariable`, у всех), причина победы — `VictoryReason`;
- событие **`RunGameState.OnRunVictory`** (хост) — сюда подписывается экран итогов (P0-13);
- на экране хоста «[Run] VICTORY: FinalBoss»;
- до P0-13 HUD у всех показывает «ПОБЕДА! Финальный босс повержен, забег пройден» (`HeroHUD.DrawRunResult`).

## Отладка (консоль хоста, ` или F1)

- `defeat_boss Start` (`ZoneA`, `ZoneB`) — засчитать босса зоны без боя (открыть путь к финалу). `defeat_boss Final` — сразу победа в забеге.
- `complete_quest Start` — квест зоны (P0-07).

## Как проверить

1. Play на `Run`. `complete_quest Start` → восток и север открыты, запад закрыт; героя в западные ворота не пускает.
2. `defeat_boss Start`, `defeat_boss ZoneA` → запад всё ещё закрыт; `defeat_boss ZoneB` → «Босс зоны «Зона B» побеждён (3 / 3) — открыто проходов: 1», западные ворота на карте зелёные.
3. Пройти на запад в финальную комнату → бой начинается («players: N»), Финальный босс 1500 HP, модель ×2.2. При 1125 HP — фаза 2 (скорость 3.2 → 3.52), появляется Blast.
4. Упасть всей группой в финальной арене → −1 день, бой сброшен (1500 HP, ожидание), группа на старте.
5. Убить босса (или `defeat_boss Final`) → «ПОБЕДА!» на экране у всех игроков; у клиента тоже.

## Отличия от UE-версии

- `LinkUnlockCondition[i]` (Name, параллельный массив) → поле `ZoneLink.UnlockCondition` (enum).
- `bIsFinalZone` → `IsFinalZone`; `BossClasses` → `BossPrefabs`; `BP_Boss_Final` / `BP_BossArena_Final` (наследники) → префабы с другими данными / `ArenaRadius`.
- Расширять `NavMeshBoundsVolume` до x = −6000 не нужно — navmesh строится по зонам.
- Единицы — метры (комната 2800 × 2800 см → 28 × 28 м, `ArenaRadius` 1050 см → 10.5 м).
- `ke * DebugDefeatZoneBoss` → `defeat_boss` (работает и для `Final`).
