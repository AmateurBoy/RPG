# Активные навыки от предметов (P0-17)

## Ассеты

| Ассет / класс | Роль |
|---|---|
| `Scripts/Skills/SkillData.cs` (`SkillData`) | Класс данных навыка (`ScriptableObject`). Одна запись = один навык. Create → TestedField → Skills → Skill. |
| `SkillConfig` | Класс конфига: список всех навыков, число слотов, клавиши слотов + `GetSkillDefinition(SkillId)`, `GetKeyLabel(slot)`. |
| `Skills` | Компонент навыков на префабе героя `Prefabs/Network/Hero`: слоты, перезарядка, использование, эффекты. |
| `SkillProjectile` (префаб `Prefabs/Network/SkillProjectile`) | Снаряд навыков типа `Projectile`: сетевой объект со сферой-моделью и точечным светом, без `NetworkTransform`. |
| `Data/Skills/DA_SkillConfig` | **Конфиг навыков** — единственный источник данных о навыках; стоит в `Skills.Config` героя, `SkillProjectile.Config` и `Resources/GameAssets`. |
| `Data/Skills/DA_Skill_*` | Навыки: `DashStrike`, `Heal`, `Fireball`. |
| `Materials/MI_Skill_Dash`, `MI_Skill_Heal`, `MI_Skill_Fireball` | Вспышки каста и материал снаряда (полупрозрачные, огненный шар — аддитивный). |

Где ещё:

- `ItemData.ActiveSkill` (P0-11) — `SkillId` навыка, который даёт предмет (пусто — без навыка).
- `HeroHUD.DrawSkillBar` / `DrawSkillSlot` / `DrawSkillIcon` — панель слотов внизу по центру.

**Новый навык простого типа без кода:** ПКМ → Create → TestedField → Skills → Skill, выбрать `EffectType` (`Dash` / `Heal` / `Projectile`), заполнить числа, добавить ассет в `DA_SkillConfig.Skills` и вписать его `SkillId` в `ActiveSkill` нужного предмета.

## Модель данных

### Навык (`SkillData`)

| Поле | Тип | Смысл |
|---|---|---|
| `SkillId` | string | Уникальный ID; по нему навык ищут, им ссылается предмет, он же ходит по сети |
| `DisplayName`, `Description` | string | Название (рисуется в слоте, если нет иконки) и описание |
| `Icon` | Texture2D | Иконка слота; пусто — в слоте пишется название |
| `ManaCost` | float | Сколько маны списывается за использование |
| `Cooldown` | float | Перезарядка, с |
| `EffectType` | enum | Механика: `Dash`, `Heal`, `Projectile` (`None` — навык не срабатывает) |
| `Damage` | float | Урон (`Dash`, `Projectile`) |
| `Distance` | float | Длина рывка (`Dash`) / дальность полёта (`Projectile`), м |
| `Radius` | float | Ширина полосы урона (`Dash`), радиус лечения (`Heal`), радиус снаряда (`Projectile`), м |
| `HealAmount` | float | Сколько HP восстанавливает (`Heal`) |
| `Speed` | float | Скорость снаряда (`Projectile`), м/с |
| `CastFlashMaterial`, `CastFlashDuration` | Material, float | Вспышка на модели героя при касте (видят все); пусто — `M_HitFlash` |
| `CastSound` | AudioClip | Звук каста; пусто — заглушка, сгенерированная в коде |
| `ProjectileMaterial` | Material | Материал снаряда (пусто — `DefaultMaterial` из `SkillProjectile`) |

Поля, не нужные механике, игнорируются.

### Механики (`EffectType`)

- **`Dash`** — рывок вперёд (куда смотрит герой) на `Distance`. Окружение (коллайдер, который не персонаж, не интерактивный объект и не триггер) останавливает рывок раньше — проверка `SphereCast` на высоте 1 м. Всем целям в полосе (капсула от старта до финиша радиусом `Radius`) — `Damage`, каждой один раз. Затем героя телепортирует его владелец (`TeleportTo`).
- **`Heal`** — все герои в радиусе `Radius` от кастующего (по горизонтали, включая его самого) получают `HealAmount` через `HeroStats.Heal`. Упавших (`IsDead`) не лечит. `Radius = 0` — только себя.
- **`Projectile`** — снаряд `SkillProjectile` появляется в 0.7 м перед героем на высоте 1.1 м и летит вперёд со скоростью `Speed` на `Distance`; первая цель на пути получает `Damage`, окружение (стена, закрытые ворота) — снаряд исчезает.

Цели урона — как у удара мечом (`Combat.CanHitTarget`): не сам герой, у цели есть `HeroStats`, она не мертва; другой герой — только при `HeroController.FriendlyFire`. Урон идёт через `HeroStats.ApplyDamage` (отбрасывание и вспышка попадания — как от удара, см. [combat.md](combat.md)).

### Конфиг (`DA_SkillConfig`)

| Поле | Значение | Смысл |
|---|---|---|
| `Skills` | `DashStrike`, `Heal`, `Fireball` | Все навыки игры |
| `SlotCount` | 4 | Число слотов навыков |
| `SlotKeys` | `Digit1`, `Digit2`, `Digit3`, `Digit4` | Клавиша каждого слота (Input System `Key`, индекс = слот). Слоты без клавиши не нажимаются — при увеличении `SlotCount` добавьте клавиши |

## Данные навыков (заглушки, баланса нет)

| SkillId | Предмет | Тип | Мана | Перезарядка | Параметры |
|---|---|---|---|---|---|
| `DashStrike` «Рывок» | `Sword` | Dash | 15 | 5 с | Damage 30, Distance 5 м, Radius 0.8 м |
| `Heal` «Лечение» | `LeatherArmor` | Heal | 25 | 10 с | HealAmount 35, Radius 4 м |
| `Fireball` «Огненный шар» | `Staff` | Projectile | 10 | 1.5 с | Damage 25, Distance 15 м, Radius 0.3 м, Speed 16 м/с |

Мана: база `MaxMana` 50, `ManaRegenRate` 2/с (`HeroStats`); посох даёт +40 и +2/с (P0-11). Регенерация маны идёт из статов (`HeroStats` на хосте) — отдельно ничего не добавлялось.

## Как устроено (`Skills`)

- **Слоты** — `slotSkills` (`NetworkList`, длина `SlotCount`, пустая строка — пусто); при изменении у всех — событие `OnSkillsChanged`.
- **Привязка к предметам** (только хост): `OnNetworkSpawn` подписывается на `Inventory.OnInventoryChanged` и сразу вызывает `RebuildSlots`. `RebuildSlots` собирает `ActiveSkill` всех надетых предметов, пропуская неизвестные ID: навык, которого больше нет среди надетых, убирается из своего слота; новый встаёт в первый свободный. Остальные навыки остаются на своих клавишах (снял броню — «Лечение» исчезло, огненный шар остался на «2»). Два предмета с одним навыком дают один слот. Если навыков больше, чем слотов, — предупреждение `[Skills] No free skill slot for: …`, лишний навык не попадает в слот.
- **Ввод** (у владельца, `Update`): клавиша `SlotKeys[i]` нажата в этом кадре → `RequestUseSkill(i)`. Пока открыт инвентарь или консоль, навыки не нажимаются.
- **Использование:** `RequestUseSkill` проверяет `CanUseSkill` на своей стороне (чтобы не слать лишние RPC); на хосте вызывает `TryUseSkill`, на клиенте — Server RPC `ServerUseSkillRpc(slot)` (хост выполняет его, только если прислал владелец героя). `TryUseSkill` (только хост) ещё раз проверяет `CanUseSkill`, списывает ману (`TrySpendMana`), ставит перезарядку, увеличивает `castCount` и запускает эффект по `EffectType`.
- **`CanUseSkill(slot)`**: в слоте есть навык с `EffectType` ≠ `None`; герой не упал и не мёртв; перезарядка закончилась; маны ≥ `ManaCost`.
- **Перезарядка** хранится по навыку, а не по слоту: параллельные `NetworkList` `cooldownSkillIds` / `cooldownEndTimes` (время — серверное время NGO, `NetworkManager.ServerTime`). Снять и надеть предмет перезарядку не сбрасывает. `GetCooldownRemaining(SkillId)` — сколько осталось (для HUD).
- **Визуал каста** — сетевой счётчик `castCount` + `lastCastSkillId`: у всех игроков вспышка `CastFlashMaterial` на модели героя и `CastSound`.

## HUD

`HeroHUD.DrawSkillBar` (вызывается в `OnGUI` перед окном инвентаря): `SlotCount` квадратов внизу по центру, масштаб от высоты экрана.

- В углу — номер клавиши. В слоте — иконка или название навыка, внизу справа — цена маны (синяя; красная и тёмный фон, если маны не хватает).
- На перезарядке — затемнение, которое уменьшается сверху вниз, и оставшиеся секунды.
- Пустой слот — тёмный квадрат с номером.
- Подсказка предмета в инвентаре показывает навык: «Навык: Огненный шар (10 MP, 1.5 с)».

## Мультиплеер

- Всё решает хост: слоты, проверка маны и перезарядки, списание маны, урон, лечение, спавн снаряда. Клиент только шлёт `ServerUseSkillRpc(slot)`.
- Синхронизируются: `slotSkills`, `cooldownSkillIds` / `cooldownEndTimes`, `castCount` / `lastCastSkillId`.
- Рывок — хост считает путь и урон, а двигает героя владелец (`TeleportRpc`), т.к. движение у владельца.
- Снаряд — сетевой объект без синхронизации движения: по сети приходит только `skillId` (задаётся до `Spawn`), каждая сторона берёт скорость/дальность/материал из `DA_SkillConfig` и двигает снаряд сама; попадание считает только хост, удаление снаряда синхронизируется. Ссылки на ассеты по сети не передаются.

Ручных шагов нет: в UE `ServerUseSkill_0` нужно было один раз пометить Replicates = Run on Server; здесь RPC объявлен атрибутом и работает у клиента сразу (см. [networking.md](networking.md)).

## Как проверить

1. Play на `TestField`. Внизу по центру — 4 слота; в «1» — «Лечение» (надета кожаная броня).
2. **I** → надеть «Меч» → в «2» появился «Рывок». Надеть «Посох» → вместо рывка в «2» «Огненный шар». Снять броню → «1» опустел.
3. Получить урон от моба, затем **1** — лечит на 35, мана −25, слот затемнён на 10 с; повторное нажатие на перезарядке ничего не делает.
4. Потратить ману (несколько выстрелов **2**) — цена в слоте краснеет, навык не срабатывает, пока мана не восстановится.
5. Рывок / огненный шар в сторону манекена — у него падает HP (30 / 25). Рывок в стену останавливается перед ней.
6. Два экземпляра (см. [networking.md](networking.md)): каст клиента работает сразу; вспышка и снаряд хоста видны клиенту и наоборот; у клиента снаряд летит синхронно с хостом.

## Отличия от UE-версии

- `PrimaryDataAsset` → `ScriptableObject`; `SkillId` — строка (по сети `FixedString32Bytes`); `EffectType` (Name) → `enum SkillEffectType`.
- `SlotKeys` (имена клавиш) → `Key` Input System; `WasInputKeyJustPressed` → `Keyboard.current[key].wasPressedThisFrame`.
- Перезарядка по `GameState.GetServerWorldTimeSeconds` → `NetworkManager.ServerTime`; массивы → `NetworkList`.
- `ServerUseSkill_0` → `ServerUseSkillRpc`, флаг Replicates ставить не нужно, хост проверяет отправителя.
- Рывок: `TeleportTo` на хосте с репликацией `CharacterMovementComponent` → телепорт через владельца; проверка стены — `SphereCast`.
- `CastSound` пусто → звук-заглушка (в UE — без звука); `CastFlashMaterial` пусто → `M_HitFlash`.
- Подсказка предмета показывает название, ману и перезарядку навыка (в UE — `SkillId`).
- Единицы — метры (`Distance` 500 / 1500 см, `Radius` 80 / 400 / 30 см, `Speed` 1600 см/с).
