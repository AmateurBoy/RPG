## Как устроен бой

1. **Арена.** Генератор (P0-06) кладёт префаб `BossArena` в слот `BossArena` каждой зоны (правило `DA_Fill_BossArena`). Хост после сборки карты (`OnMapBuiltServer`) через `BossSpawnDelay` (0.1 с) берёт префаб из `ZoneData.BossPrefabs` зоны (сейчас первый в списке) и спавнит его в центре (`NetworkObject.Spawn`). Босс к зоне жёстко не привязан: какой босс где — только данные (`DA_Zone_Start` → Громила, `DA_Zone_A` → Заклинатель, `DA_Zone_B` → Страж). Случайный выбор из пула — P2-01.
2. **Ожидание.** Босс стоит в центре (`AIState = Patrol`, но без патруля и без обнаружения). Кольцо стен арены опущено (низкий бордюр `OpenWallHeight` без коллизии — видно границу).
3. **Начало боя.** Хост каждые `CheckInterval` с проверяет арену: живой герой ближе `ArenaRadius − EnterMargin` к центру → состояние арены `Fight`: стены поднимаются (`WallHeight`, коллизия — вход закрыт), босс получает `StartFight(число игроков)`: HP × множитель от числа игроков, фаза 1, преследование; первая атака — через половину `AttackCooldown`. На экране хоста «[Arena] Fight started: Имя, players: N».
4. **Бой.** Босс выбирает цель — ближайшего живого героя внутри арены (по горизонтали не дальше `ArenaRadius` от центра). Когда прошёл `AttackCooldown` после прошлой атаки, выбирает атаку по весам среди доступных: `MinPhase ≤ фаза` и `UseRange ≥ дистанция`. Нет подходящей — подходит к цели (до `AttackRange`).
5. **Атака.** Телеграф — красный круг на земле радиуса `HitRadius`: `Front` — на `HitDistance` перед боссом, `Self` — вокруг босса, `Target` — под целью (место фиксируется в начале замаха). Через `Windup` с урон `Damage × множитель фазы × множитель игроков` всем живым героям в круге; потом `Recovery`. Кувырок (i-frames) и выход из круга спасают.
6. **Фазы.** HP ≤ порога из `PhaseHealthThresholds` → следующая фаза (за один удар можно перескочить несколько): скорость `ChaseSpeed × PhaseSpeedMultipliers[фаза]`, урон × `PhaseDamageMultipliers[фаза]`, открываются атаки с бо́льшим `MinPhase`, материал «ярости» (`EnragedMaterial`).
7. **Поражение группы.** Внутри арены не осталось живых героев (все упали — в том числе смерть всей группы из P0-04) → состояние `Idle`: стены опускаются, босс телепортируется на место, полное HP (`MaxHealth` из данных), фаза 1, ожидание. На экране хоста «[Arena] Fight reset: Имя».
8. **Победа.** Босс умер (в бою или вне его) → событие `Died` → арена `Defeated`, стены опускаются навсегда. У босса срабатывает `SpawnDrop` / `OnDropRequested` и выпадает лут по `LootTable` (P0-12, [loot.md](loot.md)) и `OnMobDied`; тело исчезает через `CorpseLifetime`. Арена вызывает `RunMap.NotifyZoneBossDefeated(zone)`: босс зоны отмечается побеждённым (у всех по центру экрана «Босс зоны «X» побеждён (N / M)…»), событие **`RunMap.OnZoneBossDefeated(zone)`** (хост), пересчёт ворот (`UpdateGates` — путь к финалу, P0-10); для финальной зоны — победа в забеге ([final-boss.md](final-boss.md)).

## Мультиплеер

Всё решает хост. Арена — не сетевой объект (строится у каждого вместе с картой); её состояние — `RunMap.arenaStates` (`NetworkList`: `Idle` / `Fight` / `Defeated`), по нему у всех поднимаются и опускаются стены (`BossArena.ApplyState`). Босс — сетевой объект (серверный `NetworkTransform`, `NavMeshAgent` только на хосте); синхронизируются `aiState`, `phase` (→ материал), `inFight`, телеграф (центр, радиус, замах, восстановление, счётчик `attackSerial`), HP (`HeroStats`). Ссылка `BossArena.Boss` есть только у хоста; HUD находит боссов через `BossBase.AllBosses`.

## HUD

`HeroHUD.DrawBossBars`: для каждого живого босса с `InFight` — «Имя — фаза N» и полоса HP с числами вверху по центру экрана (под днём забега). Видно всем игрокам, пока идёт бой.

## Данные

### `BossData` (поля сверх `MobData`)

| Поле | Смысл |
|---|---|
| `DisplayName` | Имя на HUD |
| `VisualScale` | Масштаб модели, капсулы (радиус 0.4 × масштаб, высота 1.8 × масштаб) и `NavMeshAgent` |
| `EnragedMaterial` | Материал с фазы 2 (пусто — без смены) |
| `Attacks` | Список `BossAttack` |
| `PhaseHealthThresholds` | Доли HP, на которых начинается следующая фаза (`[0.5]` — 2 фазы) |
| `PhaseSpeedMultipliers` / `PhaseDamageMultipliers` | По фазам, начиная с 1-й (не хватает элементов — берётся последний) |
| `PlayerCountHealthMultipliers` / `PlayerCountDamageMultipliers` | По числу игроков 1–4. Сейчас все 1.0 — таблица в P1-09 |

Из полей моба боссу нужны: `MaxHealth`, `KnockbackSpeed` (0 — босса не отбрасывает), `ChaseSpeed`, `AttackRange` (на какую дистанцию подходит; `stoppingDistance` агента = max(0.5, `AttackRange` × 0.8)), `AttackCooldown` (пауза между атаками, 1.2 с), `ThinkInterval`, `CorpseLifetime` (5 с), `BodyMaterial`, `LootTable`. Остальные поля атаки и восприятия моба (`AttackDamage`, `AttackWindup`, `DetectionRadius`, `LeashRadius`, …) у босса, стоящего в арене, не используются.

## Отладка

- Консоль хоста: `defeat_boss Start` (`ZoneA`, `ZoneB`, `Final`) — засчитать босса зоны без боя (босс убирается без лута, арена `Defeated`). Алиас — `DebugDefeatZoneBoss`.
- Выделенная арена в Scene view: красная окружность — `ArenaRadius`, оранжевая — радиус начала боя.
- Смена фазы пишется в консоль Unity: `[Boss] Имя phase N, speed X`.

## Как проверить

1. Play на `Run` (или `regenerate 111`). На карте зон в каждой зоне красная «Б».
2. Зайти в арену стартовой зоны → «[Arena] Fight started: Громила, players: 1», стены поднялись, вверху «Громила — фаза 1» и полоса HP. Красные круги: Swipe/Slam перед боссом.
3. Снять HP до 300 → фаза 2: материал «ярости», скорость 3.3 → 4.29 (в консоли Unity), появляется Stomp вокруг босса.
4. Упасть в арене (соло — это смерть группы) → −1 день, арена сброшена: HP 600/600, фаза 1, босс на месте, стены опущены.
5. Победить Громилу → стены опущены навсегда, у всех по центру «Босс зоны «Стартовая» побеждён (1 / 3). Проход к финалу откроется после всех боссов зон», 3 предмета на земле, «Б» на карте серая.
6. Два экземпляра: телеграфы в той же точке у клиента, «players: 2»; один упал внутри, второй снаружи → бой сбрасывается.

## Отличия от UE-версии

- Дочерние BP `BP_Boss_*` → префабы с `BossBase`, отличаются только `MobData`; новый босс-префаб нужно добавить в список сетевых префабов.
- `BossClasses` → `ZoneData.BossPrefabs`.
- Арена — не реплицируемый актор, а локальный `SlotContent`; состояние — `RunMap.arenaStates`. Босс — единственная сетевая часть карты.
- `Phase` (RepNotify) → `NetworkVariable` `phase`; телеграф (`TelegraphCenter` / `TelegraphRadius` / `CurrentWindup`) → `NetworkVariable` + счётчик `attackSerial`.
- Число игроков — подключённые клиенты (`NetworkManager.ConnectedClientsIds`) вместо `PlayerArray`.
- Единицы — метры (`ArenaRadius` 750 см → 7.5 м, Blast «до 900 см» → 9 м и т.д.).
- `ke * DebugDefeatZoneBoss` → `defeat_boss`.
